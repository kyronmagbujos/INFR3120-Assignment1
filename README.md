## 2. GUI & Interface (Requirement 2)

### Responsive Viewports (Requirement 2a)
The site uses **Fluid Design** with percentage-based widths and separate CSS files for different viewports to ensure responsiveness without the use of Flexbox.

| Viewport | Dimension | Reason |
| :--- | :--- | :--- |
| **Mobile** | `< 600px` | Single-column layout optimized for portrait smartphones. |
| **Tablet** | `601px - 1024px` | Expanded fluid width (92%) for tablets and small laptops. |
| **Desktop** | `> 1025px` | Standard laptop/desktop layout with 84% fluid main container. |

### Design Elements (Requirement 2b & 2c)
- **Color Scheme:** "A House of Bees 1" by Mary Anne Intia, sourced from Adobe Color.
- **Hex Codes:** Gold (#D6AA58), Slate Blue (#477A91), and Off-White (#E1EBF0).
- **Gradients:** A 120-degree linear gradient transitioning from Slate Blue to Gold is implemented in the site `<header>` for a professional aesthetic.
- **No Flexbox:** Strictly followed the course requirement to avoid Flexbox; all layouts are achieved using `display: inline-block`, `percentages`, and `floats`.
